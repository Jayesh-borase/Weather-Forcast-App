# Weather-Forcast-App
The Weather Forecast App is a clean and responsive React application that allows users to search real-time weather information for any city. It provides essential weather details such as temperature, humidity, minimum/maximum temperature, and overall conditions using a modern UI with Material-UI components.

This project uses the OpenWeatherMap API to fetch weather details.
API Link: https://api.openweathermap.org/data/2.5/weather

📦 Installation
git clone https://github.com/<your-username>/Weather-Forcast-App.git
cd Weather-Forcast-App
npm install
npm run dev
